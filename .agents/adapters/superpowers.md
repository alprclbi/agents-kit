# Superpowers Uyumluluğu

- `brainstorming` başlamadan önce `artifact-router` ile `spec` rolünü çöz ve explicit kullanıcı çıktı yolu olarak handoff'a ekle.
- `writing-plans` başlamadan önce `plan` rolünü çöz; native backend'de tasks aynı `plan.md` içindeki checkbox listesidir.
- `executing-plans` yalnız `work.json` içinde kayıtlı plan/tasks yolunu kullanır.
- Superpowers varsayılan `docs/superpowers/specs` veya `docs/superpowers/plans` yoluna yazmaya çalışırsa yazma öncesi engelle; yazılmışsa `stop-check` kaçak artifact olarak raporlar.
- Explicit yol desteklenmiyorsa kopya üretme veya üçüncü taraf skill'i yamama; `AKE303` bildir.
