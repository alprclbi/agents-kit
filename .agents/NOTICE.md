# Kaynak ve Köken Bildirimi

Bu kit; açık AGENTS.md biçiminden, OpenAI Codex ve Anthropic Claude Code'un resmî talimat/hook yeteneklerinden, Superpowers workflow yaklaşımından, GitHub Spec Kit ve OpenSpec'in spec odaklı geliştirme kavramlarından yararlanır.

Üçüncü taraf skill veya belge metinleri doğrudan kopyalanmamıştır. Adapter'lar ilgili sistemlerin kanonik çıktı yollarını ve yetki sınırlarını koruyan uyumluluk sözleşmeleridir. Üçüncü taraf adları kendi sahiplerine aittir; bu paket resmî bir dağıtım veya onay iddiasında bulunmaz.

Uyumluluk değerlendirmesinde başvurulan resmî kaynaklar:

- OpenAI Codex talimat ve hook belgeleri: https://developers.openai.com/codex/guides/agents-md ve https://developers.openai.com/codex/hooks
- Anthropic Claude Code bellek ve hook belgeleri: https://code.claude.com/docs/en/memory ve https://code.claude.com/docs/en/hooks
- GitHub Spec Kit: https://github.com/github/spec-kit
- OpenSpec: https://github.com/Fission-AI/OpenSpec

Bu bağlantılar uyumluluk kaynağıdır; kit ilgili projelerin markasını, onayını veya sürüm garantisini üstlenmez. Kurulumda kullanılan istemci sürümü ve trust davranışı ayrıca doğrulanmalıdır.
